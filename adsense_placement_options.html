📑 Google AdSense Ad Formats Directory & Production Snippets

Detailed breakdown of all 6 Google AdSense formats, clickability factors, and drop-in code implementations.

Publisher Ready
1. Display Ads (Leaderboard) Standard

Standard IAB sizes (728×90, 970×90, 970×250 Billboard). Fits naturally above or below the main calculation blocks.

• CTR: 1.5% - 2.5%
• eCPM: $12.00 - $18.00
• UX Score: 9.5/10 (Zero shift)
2. In-Feed Native Ads Top CTR

Blends directly into the Transaction Legs sequence. Matches row height, borders, and typography perfectly.

• CTR: 3.2% - 4.8% (Highest)
• eCPM: $16.00 - $24.00
• UX Score: 9.0/10 (Organic feel)
3. In-Article Ads High Intent

Native full-width unit inserted between calculation sections (e.g. between the calculator and the 61-day timeline).

• CTR: 2.2% - 3.4%
• eCPM: $14.00 - $22.00
• UX Score: 8.8/10 (Natural break)
4. Multiplex (Matched Content) Multi-Click

A 4×1 or 2×2 grid of content recommendations. Ideal above the footer when user has completed their simulation.

• CTR: 2.0% - 3.5%
• eCPM: $10.00 - $16.00
• UX Score: 9.2/10 (Valuable discovery)
5. Anchor Ads (Auto Ads) 95% Viewability

Sticks to the bottom screen edge. Automatically optimized by Google AI, collapses cleanly, user dismissible.

• CTR: 2.5% - 3.9%
• eCPM: $15.00 - $22.00
• UX Score: 9.4/10 (Dismissible)
6. Side Rails (Auto / Fixed) Zero Impact

Sticks in the outer margins of widescreen desktop monitors (≥1280px). Completely invisible on laptops/mobile.

• CTR: 1.2% - 2.0%
• eCPM: $18.00 - $28.00
• UX Score: 9.8/10 (Uses dead space)
